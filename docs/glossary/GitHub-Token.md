# GitHub-Token

Geheimer Schlüssel für GitHub. Ohne ihn kann der Board-Computer keine Issues anlegen. Der Kern speichert ihn verschlüsselt über den Schlüsselspeicher des Betriebssystems; der Renderer erfährt nur, ob er hinterlegt ist.
