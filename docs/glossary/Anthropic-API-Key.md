# Anthropic-API-Key

Geheimer Schlüssel für die Anthropic-API. Ohne ihn ist der Board-Computer ausgeblendet. Der Kern speichert ihn verschlüsselt über den Schlüsselspeicher des Betriebssystems; der Renderer erfährt nur, ob er hinterlegt ist.
