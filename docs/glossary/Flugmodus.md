# Flugmodus

Einstellung, die Geschwindigkeit und Treibstoffverbrauch der Navigation bestimmt: CRUISE (Standard), BURN (schnell, teuer), DRIFT (langsam, sparsam), STEALTH (schwer zu entdecken).
