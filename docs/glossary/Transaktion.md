# Transaktion

Einzelner Kauf oder Verkauf an einem Markt oder einer Werft, mit Ware bzw. Schiffstyp, Menge, Preis und Zeitpunkt. Eine Transaktion umfasst höchstens das Handelsvolumen der Ware.

Siehe auch: [Markt](Markt.md), [Werft](Werft.md), [Handelsvolumen](Handelsvolumen.md), [Credits](Credits.md).
